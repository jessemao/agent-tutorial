# Module Agent Instructions: platform-contracts

本文件继承仓库根目录 `AGENTS.md`，只规定 `platform-contracts` 的局部边界。

## 1. 模块职责

- 所有者：公共研发中心 / 技术中台。
- 定义跨业务模块共享的稳定契约和最小数据类型。
- 当前范围：审计、幂等、当前操作人和平台异常契约。

## 2. 修改范围

- 可以修改：小而稳定的接口、不可变值对象和通用异常契约。
- 不得加入：仓储业务语义、事业部特例、Web 实现、持久化实现、JPA 实体或 Repository。
- 事业部任务默认不得修改本模块；确需修改时，必须先取得技术中台批准。

## 3. 依赖与兼容

- 本模块不得依赖 `platform-web-starter`、`business-wms` 或 `training-server`。
- 新增公开契约必须说明当前调用方、复用场景及现有契约不足。
- 修改已有接口、方法、异常或数据类型时，必须列出所有调用方并说明源码兼容、行为兼容和迁移方案。

## 4. 验证

- 模块验证：`mvn -pl platform-contracts -am test`。
- 公开契约发生变化时，还必须运行受影响调用方测试和 `mvn clean verify`。
- 验证证据必须覆盖契约行为及兼容性，不得只证明本模块可以编译。

## 5. 停止条件

出现以下情况时停止并请求相关所有者裁决：

- 需要引入业务语义或事业部特例。
- 出现对下游模块的反向依赖。
- 新抽象没有真实调用方或明确复用场景。
- 公开契约变化可能破坏调用方，但影响和迁移方案尚未批准。
