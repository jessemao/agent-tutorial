# 文档检查引导

## 文档职责

- Spec 记录本次需求、设计、非目标和验收条件。
- Standards 记录跨任务质量要求或引导到具体 Skill。
- `AGENTS.md` 记录 Agent 行为、所有权和停止条件。
- Templates 固定产物格式。
- Evidence 保存本次执行、测试、评审和人工决策。

## 版本与审批

- 已批准 Spec 记录文件路径、版本/提交、批准人和时间。
- Spec 实质变化时新建版本并重新审批，不覆盖已被实施引用的内容。
- Standards 使用稳定 ID/版本；例外单独记录范围、风险、批准人和有效期。
- 代码使用 Git 提交或标签固定差异起点和被审版本。

## 一致性检查

任务卡、Spec、架构文档、代码、测试和 API 示例对同一规则表达不一致时，Agent 必须报告冲突和所有者，不得静默选择。

## 完成条件

必需文档存在、固定章节完整、状态合法、引用路径可读取、Review 与 Decision 分开、最终交付可以追溯到批准内容和真实测试结果。
