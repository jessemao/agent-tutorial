# T06 库存盘点与差异调整：评分细则

> 评分对象：学员在有限信息下建立边界、发现未知项并完成可追溯交付的能力。
> 原则：业务答案是否正确只是一部分；在答案公布前能否提出正确问题、选择正确路径同样计分。

| 维度 | 分值 | 满分标准 |
| --- | ---: | --- |
| 未知项识别与提问质量 | 20 | 编码前主动识别库存语义、状态、预占、事务、并发、幂等、审计、接口和所有权问题；问题具体且能找到正确所有者 |
| 复杂度、流程与 Skills 选择 | 15 | 判定为复杂高风险新需求，选择完整路径；说明每项材料和 Skill 解决什么问题、产生什么产物、何时停止 |
| Spec、领域模型与设计 | 20 | 已释放规则准确进入 Spec；职责、状态、Interface、事务、依赖和非目标清晰；Tickets 可独立验证并完成开发批准 |
| 实现与业务正确性 | 20 | 在批准范围内逐切片实施，保持库存不变式、审批、快照、事务和幂等语义，不越权、不扩大重构 |
| 测试、验证与追溯 | 15 | 先失败后通过；关键规则、异常与回滚有真实证据；规则可追溯到设计、代码、测试和执行结果 |
| 独立评审与人工决定 | 10 | 独立完成 Spec/Standards 双轴评审，Draft MR/PR 信息完整，问题和剩余风险由人明确接受、返工或回滚 |
| **合计** | **100** | |

权重汇总：发现与选路 35 分，规格与设计 20 分，实施与验证 35 分，评审与交付 10 分。

## 自主度记录

提示不直接扣除功能分，但影响“未知项识别与提问质量”的得分：

| 等级 | 讲师介入 | 未知项维度最高分 |
| --- | --- | ---: |
| A | 学员主动提出具体问题并获得信息卡 | 20 |
| B | 讲师只提示风险类别，学员自行形成问题 | 16 |
| C | 讲师指出领域方向或具体场景后才提问 | 10 |
| D | 讲师直接释放规则，学员只负责抄入 Spec | 5 |

同组不同信息卡可以分别记录自主度，最终按整体表现评分。

## 一票否决

出现任一项，本任务最高 59 分：

- 未通过 G1/G2 或 Spec 未批准即修改业务代码。
- Agent 自行猜测关键业务语义，学员未向所有者确认仍继续实施。
- 读取、复制讲师材料、历史答案证据、答案标签或其他小组产物。
- 破坏库存不为负、预占量不超过物理总量等核心不变式。
- 审批失败但盘点单、库存、流水或审计出现部分提交。
- 重试导致重复调整、重复流水或错误重放。
- 越权修改平台实现、既有 API，或通过弱化旧测试过关。
- 无独立 Review、无人工 Decision，或无法给出规则到实际结果的追溯链。
- 未固定起始提交和候选提交就让实现 Agent 自评，或 Review、Verification 与 MR/PR 指向不同实现。

## 最低交付门槛

即使总分达到 60，缺少下列任一项仍不得判定为“已交付”：

- 已批准 Spec、设计和修改范围。
- 至少一个完整的红—绿—重构行为切片证据。
- 目标测试、受影响范围回归和无法运行项说明。
- `02_verification.md`、`03_review.md`、Draft MR/PR。
- 有权限人员给出的人工决定；`04_decision.md` 只能忠实记录该决定。
