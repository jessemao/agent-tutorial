# T04 统一库存业务入口：评分细则

| 维度 | 分值 | 满分标准 |
| --- | ---: | --- |
| 重构前行为快照 | 20 | 先证明11条测试通过，列出对外行为 |
| 边界与重复识别 | 15 | 找出分散入口及幂等、校验、流水和审计风险 |
| 重构方案 | 15 | 小步、可验证，不改外部契约，不引入推测性抽象 |
| 代码质量 | 20 | 唯一公开入口，业务不变式和事务保留 |
| 等价性证据 | 20 | 重构后同一套11条测试通过，API和错误不变 |
| AI 输出裁决 | 5 | 记录拒绝或修改过度重构建议 |
| 风险与复盘 | 5 | 能说明收益、未改动内容和剩余风险 |
| **合计** | **100** | |

## 一票否决

- 未建立行为快照就开始重构。
- 通过修改或删除旧测试来使新结构通过。
- 改变 HTTP 契约、错误码或库存语义。
- 破坏移库原子性、幂等或锁顺序。
- 引入没有当前业务用例支撑的通用框架。
