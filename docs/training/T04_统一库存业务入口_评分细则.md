# T04 统一库存业务入口：评分细则

> 评分对象：行为保持、边界改善、最小迁移和回归证据。  
> 限制：代码变短、类变多、使用设计模式或测试全绿均不能单独证明重构成功。

| 维度 | 分值 | 满分标准 |
| --- | ---: | --- |
| 重构前行为记录 | 20 | 运行批准的回归集并列出对外行为、调用方和最终状态 |
| 边界与重复识别 | 15 | 找出分散入口及幂等、校验、流水和审计风险 |
| 重构方案 | 15 | 小步、可验证，不改外部契约，不引入推测性抽象 |
| 代码质量 | 20 | 唯一公开入口，业务不变式和事务保留 |
| 等价性证据 | 20 | 重构后同一回归集通过，API、错误和事务结果不变 |
| AI 输出裁决 | 5 | 记录拒绝或修改过度重构建议 |
| 风险与复盘 | 5 | 能说明收益、未改动内容和剩余风险 |
| **合计** | **100** | |

## 一票否决

- 未建立当前行为记录就开始重构。
- 通过修改或删除旧测试来使新结构通过。
- 改变 HTTP 契约、错误码或库存语义。
- 破坏移库原子性、幂等或锁顺序。
- 引入没有当前业务用例支撑的通用框架。
