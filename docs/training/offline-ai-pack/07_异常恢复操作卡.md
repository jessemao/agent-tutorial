# 异常恢复操作卡

## 1. 60秒决策

| 现象 | 判定 | 立即动作 | 继续授课材料 |
|---|---|---|---|
| AI超时、报错或无法访问 | AI不可用 | 停止重试，标记预置产物 | 01、02、03、04、05 |
| AI直接写表/API，不输出未知项 | 需求审核偏离 | 把当前输出当负例，切到02 | 标准需求审核输出 |
| AI修改平台、删测试或扩大范围 | 实施越界 | 立即停止Agent，保存Diff，转评审 | 03、04、05 |
| AI评审无定位/证据或只说“没问题” | 评审偏离 | 不循环追问，切到04由学员裁决 | 标准代码评审输出 |
| Git目录污染或学员无法恢复 | 环境异常 | 保留原目录，使用新干净目录切`s2` | 06恢复索引 |
| Maven依赖无法下载 | 网络/缓存异常 | 切已暖机讲师机；无可运行环境则使用预置测试证据 | 06 + 任务讲师参考 |

## 2. 处理级别

- **L1证据提示**：只问“证据在哪里”，不指文件。
- **L2边界提示**：指向模块、所有权或不变式。
- **L3定位提示**：给文件或失败测试，不给代码。
- **L4恢复点**：已无法在本时段完成；保存学员差异后切干净起点/答案对照。

L3/L4必须记录，不计为学员完全独立完成。

## 3. 助教故障记录

```text
时间：
任务/小组：
受影响人数：
异常类型：AI / 网络 / 依赖 / Git / 设备 / 时间
已保留的学员证据：
采用级别：L1 / L2 / L3 / L4
使用的预置文件/标签：
当堂完成什么：
什么仍未验证：
课后补验所有者和截止时间：
```

## 4. 不得采取的恢复方式

- 不在学员有未保存差异的目录里强制切标签或覆盖答案。
- 不删除断言、异常处理或质量门以让构建变绿。
- 不让讲师代替学员手写整个答案。
- 不将预置产物标记成现场AI或学员的独立产物。
- 不在投影上长时间即兴排查环境；超过时间阈值就切恢复点。
