# T05 平台组件与 Skill 复用：评分细则

> 评分对象：复用决策、平台边界、接入证据和可重复执行的 Skill 产物。  
> 限制：减少重复代码或成功调用 Skill 不能单独得分；无真实调用方或业务语义泄漏属于阻塞项。

| 维度 | 分值 | 满分标准 |
| --- | ---: | --- |
| 复用决策 | 20 | 区分通用机制、业务语义和不应抽取的重复 |
| 平台契约 | 15 | 契约最小、不包含仓储语义、依赖方向正确 |
| 默认实现与接入 | 20 | 审计/幂等机制可复用，库存与出库仍表达自己的语义 |
| 契约测试与回归 | 15 | 组件正常/冲突路径有测试，批准的原业务回归集通过 |
| 需求审核 Skill | 10 | 触发、输入、产物、证据和停止条件完整，有运行产物 |
| 代码评审 Skill | 10 | 同时审规范与需求，问题可定位且有优先级，有运行产物 |
| AI 裁决与风险 | 10 | 记录采纳/拒绝理由，说明抽象边界和剩余风险 |
| **合计** | **100** | |

## 一票否决

- 将 SKU、库位、出库单状态等业务语义放入平台组件。
- 通过删除、改弱测试或修改对外契约使结果通过。
- 幂等冲突被当成成功重放，或业务事务语义被破坏。
- Skill 只是一段通用提示词，没有证据要求和停止条件。
- 没有 Skill 实际运行产物却宣布完成。
