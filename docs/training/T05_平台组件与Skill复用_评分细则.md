# T05 平台组件与 Skill 复用：评分细则

> 评分对象：真实重复识别、职责分层、项目 Skill 契约、跨任务验证和交付证据。
> 限制：Skill 文件存在或成功运行一次不能单独得分；业务答案泄漏、越权写入或自动批准属于阻塞项。

| 维度 | 分值 | 满分证据 |
| --- | ---: | --- |
| 建档与重复证据 | 15 | 从 T01～T04 引用重复 Prompt；清楚排除任务变量、业务规则和实现答案 |
| 五层职责分离 | 15 | 人、项目 Skill、AI Hero、参考 Skill、门禁边界明确且没有重复包办 |
| 五个项目 Skill 契约 | 20 | 每个契约具备触发、输入、读取、允许写入、输出、停止条件和禁止动作 |
| 任务路由与裁剪 | 10 | T01～T04 分别选择正确专业路径，能解释无 Spec/无 Tickets/不强造 Red 等裁剪 |
| `work-item-start` 实现/评审 | 15 | 只负责建档，正确使用模板，冲突/缺材料/附件异常时停止且不覆盖 |
| 跨任务验证 | 15 | T01/T02、两个独立会话、成功/失败路径均有真实日志且输出一致、输入隔离 |
| 独立 Review 与交付 | 10 | 固定 Diff 双轴 Review、人工 Findings、草稿 MR/PR 和 `04_decision.md` 可追溯 |
| **合计** | **100** | |

## 一票否决

1. 没有真实重复证据，只写一个泛化 Prompt 就称为 Skill。
2. 将单号、数量、根因、业务规则、类名答案或人工决定写死进 Skill。
3. 项目 Skill 复制 AI Hero/Standards 的完整方法，或允许自己批准、裁决、合并。
4. `work-item-start` 覆盖已有目录或越阶段生成 Analysis、Spec、代码、Review、Decision。
5. 没有至少两个任务、两个独立会话和失败停止路径的运行证据。
6. 未固定候选 Diff 就自评，或 Agent 替人作出最终 Decision。

## 扣分指引

- 只列重复内容，没有说明应落在哪一层：重复证据项最高 7 分。
- 五个契约只写名称/作用，没有输入、写入范围或停止点：契约项最高 5 分。
- 所有任务都调用同一专业 Skill 链：路由项不得分。
- 验证只有成功路径，未证明确实会停止：跨任务验证项最高 7 分。
- 输出一致但业务输入串线：跨任务验证项不得分并阻塞交付。
- MR/PR 缺 Work Item、Verification 或 Review 链接：交付项最高 5 分。

- [ ] 候选提交、Review、Verification 与 MR/PR 版本一致，阻塞项关闭
