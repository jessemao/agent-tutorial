# T03 从零新建同仓库库内移库：评分细则

| 维度 | 分值 | 满分标准 |
| --- | ---: | --- |
| 需求审核 | 20 | 识别库存口径、范围、失败语义、幂等、流水、并发和审计 |
| 领域与契约 | 15 | 命令表达完整动作，不用两次 HTTP 拼装 |
| 所有权和影响面 | 10 | 规则留在仓储模块，只复用平台契约 |
| 代码正确性 | 25 | 原子修改源/目标，保持总量和非负不变式，固定锁顺序 |
| 测试与证据 | 20 | 正常、幂等、回滚、非法输入和原有回归有真实证据 |
| AI 输出审核 | 5 | 能拒绝越界、非原子和过度抽象方案 |
| 风险说明 | 5 | 不隐瞒并发创建目标余额等未完全验证风险 |
| **合计** | **100** | |

## 一票否决

- 未澄清需求直接编码。
- 用两个独立 HTTP 请求模拟移库。
- 来源扣减和目标增加不在同一事务。
- 允许可用库存为负或移动已预占库存。
- 绕过 `InventoryOperations` 从 Controller 操作 Repository。
- 没有自动化测试或将 AI 声明当作证据。
