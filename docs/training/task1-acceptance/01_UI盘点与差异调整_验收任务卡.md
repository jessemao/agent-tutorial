# 任务卡 A：UI 盘点与差异调整

## 1. 验收目标

验证用户可从库存盘点页面完成创建、实盘、提交、审批和差异调整，并在刷新后继续看到结果。

## 2. 角色与对象

- 操作者：测试工程师。
- 见证人：项目经理 / 业务所有者。
- 候选对象：已固定的 Git 提交和对应运行环境。

## 3. 前置数据

- 浏览器地址：`http://localhost:8080`。
- 仓库：`1`；货位：`1`；SKU：`303`。
- 初始可用量：`10`；预留量：`0`。
- 实盘量：`12`；预期差异：`2`。

## 4. 操作步骤

1. 打开课堂页面，进入“仓储管理 → 库存盘点”。
2. 确认仓库、货位、SKU 和实盘量均可见，将实盘量设为 `12`。
3. 点击“创建盘点”，核对状态为 `DRAFT`。
4. 点击“确认实盘”，核对状态为 `COUNTED`、差异为 `2`。
5. 点击“提交”，核对状态为 `SUBMITTED`。
6. 点击“审批并调整”，核对状态为 `ADJUSTED`、差异为 `2`、流水为 `1 条`。
7. 点击“刷新”，再次核对 `ADJUSTED`、差异 `2` 和流水数量。

## 5. 通过条件

- [ ] 页面入口、字段和业务按钮可见，操作中无需内部 ID 或数据库操作。
- [ ] 状态依次为 `DRAFT → COUNTED → SUBMITTED → ADJUSTED`。
- [ ] 差异为 `2`，且只有一条调整流水。
- [ ] 刷新查询后结果不丢失。
- [ ] 实际结果、候选提交和时间已记录。
