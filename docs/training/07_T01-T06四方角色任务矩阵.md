# T01—T06角色任务矩阵（测试与 QA 分列）

> 用途：明确技术中台、UI、仓储事业部、测试工程师和 QA 在每个任务中的决策权、输入和交接。  
> 限制：技术中台与 UI 可兼任，但测试工程师与 QA 必须是不同团队的不同人员，但批准责任不能由 Agent 代替；跨所有权事项在责任方确认前不得编码。

> 角色：技术中台、UI团队、仓储事业部、独立测试团队、QA团队。  
> 目标：让每个任务都有明确输入、决策权、交付物和交接点，避免把课程做成事业部单独编码。

## 1. 固定职责与修改边界

| 角色 | 对什么负责 | 可确认 | 不得单方决定 | 主要交付 |
|---|---|---|---|---|
| 技术中台 | `platform-contracts`、`platform-web-starter`、公共组件和核心Skills | 公共能力是否存在、如何复用、兼容策略 | 仓储业务规则和UI展示细节 | 复用决策、平台变更评审、契约测试 |
| UI团队 | 公司级页面、状态、字段、错误展示规范 | UI契约影响和展示规则 | 后端业务状态机和事务规则 | UI影响清单、契约确认、兼容结论 |
| 仓储事业部 | `business-wms`业务规则、数据、API和对应测试 | 仓储术语、业务状态、不变式和验收条件 | 平台内部实现和UI公司级规范 | 需求澄清、代码、单元/集成测试、剩余风险 |

## 3. 课堂分组用法

- 每组5—7人，各职责必须有人承担，测试工程师与 QA 单独分配；人数不足时技术中台与UI角色可由一人兼任。
- 每项任务开始时交换角色，避免只有研发人员操作Agent。
- 事业部是代码主要实施者；涉及平台、业务或 UI 契约变化时，开发负责人先取得对应规则确认，再独立批准进入实施。
- 平台和UI角色不是“反馈人”，必须产出可进入Agent上下文的契约与裁决。
- 测试工程师与 QA 不批准开始编码；前者独立测试，后者独立审核，不以“AI评审通过”代替各自人工结论。

## 4. 统一交接单

每次从需求审核进入AI Coding前，小组必须合并以下内容：

| 产物 | 责任角色 | 必填内容 |
|---|---|---|
| 业务决策 | 仓储事业部 | 事实、假设、待确认、状态和验收条件 |
| 平台复用决策 | 技术中台 | 已有能力、允许接口、禁止修改和兼容要求 |
| UI契约结论 | UI团队 | 字段、状态、错误展示和旧客户端影响 |
| 独立测试计划 | 测试工程师 | 功能与风险场景、测试层级、数据、预期和失败判定 |
| QA 审核计划 | QA | 规范、追溯、覆盖、证据和缺陷闭环检查 |

各方输入合并后生成唯一 `Spec 版本`。业务、平台和 UI/契约所有者分别确认自己负责的规则，QA 审核可测性；最终由受影响代码的开发负责人批准实施目标和修改范围。任何实质变更必须生成新版本并注明 `Supersedes`，不得覆盖已确认版本。

## 5. 验收标准

- 各角色在T01—T06都有可评分产物，无角色长时间空闲。
- 每次 Agent 编码前，相关规则输入已经合并，并由开发负责人批准实施目标和修改范围。
- 任何越界修改都能由所有权矩阵判定，并有对应所有者的人工确认。
- 测试工程师根据实际执行出具测试结论，另一团队 QA 根据证据出具质量审核结论，最终放行由交付负责人决定，不由 Agent 自我声明完成。
- 最终证据必须能从 Spec 条目追溯到代码位置、测试用例、执行结果和人工结论。

## T01—T03 测试与 QA 交接口径

开发仅提交当前任务的 TDD 与必要回归（`02_verification.md`）；代码评审记录于 `03_review.md`。测试团队的工程师独立执行功能、页面/API、异常和回归验证，结果写入 `functional-test.md`；另一团队的 QA 审核规范、需求追溯、覆盖、证据和缺陷闭环，结论写入 `qa-review.md`。业务所有者另行验收，交付负责人在 `04_decision.md` 记录最终裁决。不能用开发全绿替代独立测试，不能用 QA 审核替代业务验收。

各阶段分别记录对象版本、具名负责人及团队、待确认事项、状态、结论时间与证据。测试工程师与 QA 不得由同一人员兼任；缺少负责人由讲师/交付负责人指定，未执行保持待执行，未确认保持待确认，不预填 PASS。修复后先更新开发证据，再由测试工程师重测，QA 审核新证据，必要时重新业务验收。

T01 仍按完整手写 Prompt 操作；职责分离不意味着引入预置 Skill。T02/T03 保留各自命令入口。操作与模板以对应学员卡及 `docs/ai-governance/roles-and-approvals.md` 为准。
