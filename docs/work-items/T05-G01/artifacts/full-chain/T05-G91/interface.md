## 契约范围

- 类型：项目 Skill 命令 / 只读 Module Interface。
- 新增、修改或保持的契约：新增显式 `/work-item-status <work-item-id>`；保持五个阶段入口、Workflow 和人工权限不变。
- 明确非目标：不提供 HTTP/UI、JSON、缓存、列表查询、写入命令或自动阶段推进。

## UI 交互契约

- 页面入口与完整操作路径：无业务页面；在会话中显式输入命令，读取返回的状态报告后由人决定是否执行下一动作。
- 字段标签、业务值、默认值和可编辑/只读/可选择状态：Work Item ID 必填；报告字段固定且只读；未知信息明确显示，不默认 PASS。
- 系统生成标识与连续操作、重试、冲突行为：不生成 ID；相同证据允许重复查询；证据改变时重新计算；冲突不任选来源。
- 成功与失败反馈、结果明细及保留行为：成功返回完整字段；失败返回稳定错误、停止原因和证据，不改变上次有效仓库状态。
- 列表、查询、筛选、刷新及重新进入后的行为：只支持按单个 ID 查询；新会话重新读取仓库，不依赖聊天记忆或缓存。

## 错误与边界行为

| 条件 | HTTP/错误码/异常 | 调用方行为 | 最终状态 |
| --- | --- | --- | --- |
| ID 非法或规范化后越出 Work Item 根目录 | `WORK_ITEM_NOT_FOUND` | 不探测或回显边界外内容；核对合法 ID | 仓库不变，无下一入口 |
| Work Item 目录不存在 | `WORK_ITEM_NOT_FOUND` | 核对 ID；不得自动建档 | 仓库不变，无下一入口 |
| 判断阶段所需证据缺失 | `WORK_ITEM_STATUS_INCOMPLETE` | 交由对应责任人补齐或确认 | 仓库不变，无下一入口 |
| README、阶段产物、人工确认或 Git 相互冲突 | `WORK_ITEM_STATUS_CONFLICT` | 查看列出的来源并人工裁决 | 仓库不变，无下一入口 |
| 必要证据不可安全读取 | `WORK_ITEM_EVIDENCE_BLOCKED` | 由数据/治理所有者处理权限或安全问题 | 仓库不变，无下一入口 |
| 负责人未具名但其他证据一致 | 非错误 | 返回真实阶段；下一动作是讲师/交付负责人指定角色 | 仓库不变 |

## 兼容、迁移与回滚

- 旧调用方影响：五个阶段 Skill 和现有长 Prompt 保持可用；新查询是附加能力。
- 兼容窗口/版本策略：项目 Skill 由 `skills-lock.json` 固定内容哈希；输出契约变化需重新审批和更新锁记录。
- 迁移步骤：无需迁移；调用者按需采用新显式命令。
- 回滚方式：删除新 Skill 目录并撤销锁文件登记。
