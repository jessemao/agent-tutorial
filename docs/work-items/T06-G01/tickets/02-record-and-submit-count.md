## 交付行为

用户可在盘点草稿中增删明细、部分录入实盘总量并整表保存；未填写与零保持不同语义。全部明细填写后，用户提交盘点，系统记录提交时账面快照、最后提交人和时间，并将盘点变为只读待审核状态。页面在每次成功后使用完整服务端详情刷新；并发编辑、校验和幂等冲突保留用户输入并展示服务端有效版本。

## 修改边界

- 允许修改：`business-wms` 盘点聚合的草稿保存/提交、版本与动作回执、相应 HTTP Adapter；`training-server` 的草稿录入/提交页面和集成测试。
- 禁止修改：平台 Modules、库存余额/流水调整、批准/驳回/取消行为、Ticket 01 已批准契约、治理规范和第三方 Skills。
- Module `AGENTS.md`：必须遵守根规则、`business-wms/AGENTS.md` 与 `training-server/AGENTS.md`。
