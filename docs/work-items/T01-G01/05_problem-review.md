# 05 Problem Review：T01-G01

## 问题如何发生

- 直接原因：`ShipmentService.cancel` 在 RESERVED 分支计算出需要释放库存，但库存释放调用被注释掉；订单状态仍变更为 `CANCELLED`。
- 系统性原因：取消编排未同时保护单据状态、库存余额和库存流水的最终一致性。
- 为什么现有测试/评审没有更早发现：缺陷引入后目标测试可直接暴露问题；页面只看单据状态会漏掉库存残留。

| 自动化测试 | 保留公开 API 目标测试，覆盖取消后的库存最终状态和释放失败回滚 | 开发负责人、QA | 待 QA 复测后确认 |
