## 错误与边界行为

| 条件 | HTTP/错误码/异常 | 调用方行为 | 最终状态 |
| --- | --- | --- | --- |
| 服务未连接 | 网络错误 | 停止并提示检查 Docker | 不伪装完成 |
| API 业务失败 | 保留后端 `code/message` | 停止后续步骤并记录响应 | 不读取失败 `data` |
| 完整流程已执行 | N/A | 禁用再次执行，引导换数据 | 保留当前证据 |
