## 变更目标

- 使用 `southliu/south-admin-react` 的 React、Vite、Ant Design 技术栈和管理后台布局重构现有静态页面。
- 保留 T01 的真实业务操作：新增演示单、取消出库、查询出库单和库存明细。
- Spring Boot 继续提供同源页面和 API，学员仍只需访问 `http://localhost:8080/`。

## 范围

- 新增可维护的 React + TypeScript 前端源码与锁定依赖。
- 使用 South Admin 的侧栏、顶部栏、页签、内容区、筛选表单、数据表格、对话框和反馈模式。
- 使用静态菜单，不请求用户、权限或菜单接口。
- 构建后的静态资源输出到 `training-server/src/main/resources/static/`。
- 保持桌面教学投屏清晰，并支持窄屏基本操作。

## 非目标

- 不实现登录、Token、角色、权限、动态菜单、路由鉴权或修改密码。
- 不迁入 South Admin 的系统管理、国际化、KeepAlive、图表、富文本和其他演示模块。
- 不修改 WMS API、业务规则、事务、数据库或 T01 缺陷与答案。
- 不要求课堂运行时启动 Node 服务；Node 只用于前端构建。

## 设计决定

| ID | 决定 | 理由 |
| --- | --- | --- |
| DEC-06 | 将 South Admin 作为 MIT 项目模板进行最小化适配，而不是复制整个仓库 | 保留真实框架结构，避免无关依赖和鉴权逻辑进入课程 |
| DEC-07 | 使用 React 19、Vite 7、Ant Design 6 和官方图标依赖；Vite 升至同主版本安全补丁 7.3.6 | 与固定上游技术栈对齐，同时关闭已公开的开发服务器路径穿越风险 |
| DEC-08 | 采用静态菜单和本地视图状态 | 用户明确不需要鉴权和动态权限复杂度 |
| DEC-09 | 构建产物提交到 Spring 静态目录 | 保持现有 Docker 和课堂启动路径不变 |
| DEC-10 | 页面只呈现业务事实，不给出根因和修复代码 | Agent 负责定位，人负责批准与验收 |
