# T03 代码版本说明

T03 是从零新建需求，不制造故障实现。

| 版本 | 内容 |
| --- | --- |
| S2-T03 | T02 完成后的正确版本；不存在移库 API、命令和测试 |
| S3-T03 / 当前 S0 | 完整移库领域入口、Web 适配器、第二演示库位和3条移库测试 |

学员起始版使用 `s2-t03-start` 标签；标准答案使用 `s3-t03-answer` 标签。

S3 执行 `mvn clean verify`，预期 11 条集成测试全部通过，其中3条移库测试验证正常移动、幂等重试和来源不足回滚。

## 课堂切换

```bash
# 学员起点：8条测试，无移库功能
git switch --detach s2-t03-start

# 讲师答案：11条测试，含移库功能
git switch --detach s3-t03-answer
```

学员实操时应从 `s2-t03-start` 创建独立工作分支，不直接修改标签。
