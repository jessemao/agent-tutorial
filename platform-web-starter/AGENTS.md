# Module Agent Instructions: platform-web-starter

本文件继承仓库根目录 `AGENTS.md`，只规定 `platform-web-starter` 的局部边界。

## 1. 模块职责

- 所有者：公共研发中心 / 技术中台。
- 提供统一响应、异常映射、审计和幂等的通用 Web 实现。
- 只实现跨业务可复用的技术机制，不解释任何事业部业务状态或业务规则。

## 2. 修改范围

- 可以修改：`ApiResponse`、统一异常处理、平台契约适配器及通用 Web 组件。
- 不得加入：库存、入库、出库、移库、盘点等仓储判断，或任何单一事业部的硬编码行为。
- 不得复制业务模块代码来实现所谓平台复用。

## 3. 依赖与契约

- 只允许依赖 `platform-contracts` 及已批准的 Spring Web / Validation 能力。
- 不得依赖 `business-wms` 或 `training-server`。
- 统一异常处理不得吞掉失败、伪造成功、泄漏内部堆栈或静默改变公开错误契约。
- 审计和幂等实现必须保持线程安全，不得记录令牌或业务敏感信息。
- 新增公共组件必须提供真实调用方、稳定接口和契约测试。

## 4. 验证

- 模块验证：`mvn -pl platform-web-starter -am test`。
- 响应、异常、审计或幂等契约变化时，还必须运行 `mvn -pl training-server -am test` 和 `mvn clean verify`。
- 验证必须覆盖成功、失败和重复调用，不得只检查返回类型。

## 5. 停止条件

出现以下情况时停止并请求技术中台及受影响调用方批准：

- 需要新增依赖或改变公开响应、字段、状态码或错误码。
- 需要引入事业部语义或对业务模块的反向依赖。
- 线程安全、异常传播或敏感信息处理方式发生变化。
- 公共抽象没有真实复用证据。
